# 全局填色完整性规则

适用于所有产品的 Color Guide 和 Finished Preview，不存在按产品名称或区域面积绕过检查的例外。

1. 应上色区域必须先有闭合边界；漏口须在 Line Art 阶段修补后重新审核区域，不用隐藏边界掩盖错误。
2. 每个白色连通区域必须明确归入 `regions`（单一颜色）或 `intentional_white`（附设计留白理由）。包括外部背景和 1px 小区域。禁止默认将未分类区域留白。
3. 线稿尺寸与像素哈希必须匹配审核方案。所有种子点、预期面积、区域唯一性必须有效。上色区域接触外部画布边缘时拒绝执行。
4. 复查身体、角、尾巴、翅膀、装饰花纹、花瓣、云朵及边缘微小区域。区域的语义仍需人工确认；不得为消除报警把误漏区域随意标为设计留白。
5. Color Guide 与 Finished Preview 共用区域定义和 RGB 调色表，不允许分别生成或修图。
6. 检查真正导出的两张 PNG：应上色掩码内部任意白像素都作为异常白洞，不设置可忽略的小面积阈值。输出异常数量及位置／面积；颜色不符、原线条变化、设计留白被填色也失败。
7. 任一检查失败，返回 QUALITY FAILED／错误结果并要求修补或审核，不替换已有产品，不写入新的通过状态。新元数据只在所有检查通过后保存，发布状态仍为 draft。

自动检测保证相对于明确审核过的区域设计不存在漏填；它不能自行推断一片白色在艺术语义上是否属于云、背景或身体。新增／改动线稿必须重新做语义审核。
